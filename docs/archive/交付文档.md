```text
django_server/

│   ├── settings.py
│   ├── urls.py

│   └── asgi.py
├── api/
│   ├── urls.py                # REST 路由
│   ├── views.py               # REST 视图
│   └── apps.py
└── runtime/
    ├── agent_runtime.py       # AB 单用户 Runtime
    └── a_interface.py         # A 侧预留接口
```

### 核心功能

- **REST API**：向 C 暴露行程、事件、预约、Action、工具、导出、状态、决策历史等。
- **Runtime**：在 Django 进程内维护 B 侧工具、监控、执行、预约、事件。
- **A 接入点**：通过 `decision_hook` 接收决策请求，通过 `ToolProvider` 调用工具。

## 三、面向 A

### 3.1 A 的代码放在哪里

建议 A 在 `django_server/` 下新建一个 `a_side/` 包：

```text
django_server/
└── a_side/
    ├── __init__.py
    ├── llm_decision_engine.py   # A 的 LLM Decision Engine
    ├── planner.py               # A 的 Planner / Route Planner
    └── memory.py                # A 的 Memory / 用户画像（可选）
```

关键接入文件是：

```text
django_server/runtime/a_interface.py
```

A 只需：

1. 实现 `ADecisionEngine`；
2. 修改 `build_decision_hook()` 返回自己的引擎。

示例：

```python
# a_side/llm_decision_engine.py
from core.schemas import DecisionRequest, ReplanRequest
from runtime.a_interface import ADecisionEngine

class MyLLMDecisionEngine(ADecisionEngine):
    def __init__(self, tool_provider=None):
        self.tool_provider = tool_provider

    def __call__(self, req: DecisionRequest) -> ReplanRequest | None:
        # 在这里调用你的 LLM
        ...
        return ReplanRequest(
            new_timeline=...,
            reason="...",
            diff_summary=["..."],
        )
```

然后在 `runtime/a_interface.py` 中：

```python
def build_decision_hook(tool_provider=None):
    return MyLLMDecisionEngine(tool_provider=tool_provider)
```

### 3.2 A 的 LLM 思考时如何调用封装好的工具

A 的 LLM 在 `decision_hook` 内可以拿到：

```python
req.context["tool_specs"]   # 工具清单
tool_provider               # 由 AgentRuntime 注入
```

#### 方式一：进程内调用（推荐）

```python
# 1. 查看可用工具
tools = self.tool_provider.list_tools_json()

# 2. 调用工具
result = self.tool_provider.call_json("weather", {"city": "北京"})
result = self.tool_provider.call_json("scenic", {"place": "故宫"})
result = self.tool_provider.call_json("traffic", {
    "origin": "北京",
    "destination": "故宫",
})
```

返回格式：

```json
{
  "tool": "weather",
  "status": "ok",
  "data": { "...": "..." },
  "error": null,
  "source": "mock",
  "elapsed_ms": 12.3,
  "timestamp": "2026-08-21T12:00:00"
}
```

默认白名单只读工具：

- `weather`
- `weather_warning`
- `air_quality`
- `weather_forecast`
- `map`
- `traffic`
- `scenic`
- `food`
- `web_fetch`
- `web_search`

`booking` 等有副作用工具默认**不**对 A 的 LLM 开放。

#### 方式二：HTTP 调用

```http
POST /api/tools/invoke/
Content-Type: application/json

{
  "name": "weather",
  "arguments": {"city": "北京"}
}
```

该入口同样只允许只读工具。

### 3.3 A 如何向 B 注入时间轴

#### 方式一：进程内注入（推荐）

A 的 Planner / Route Planner 生成 `TripTimeline` 后，直接写入 Runtime：

```python
from runtime.agent_runtime import runtime
from core.schemas import TripTimeline, DayPlan, Place

timeline = TripTimeline(
    city="北京",
    start_date=...,
    end_date=...,
    days=[DayPlan(...)],
)

runtime.init_timeline(timeline)
# 或
runtime.set_timeline_from_payload(payload_dict)
```

#### 方式二：通过 API 注入

```http
POST /api/timeline/
Content-Type: application/json

{
  "city": "北京",
  "start_date": "2026-08-01",
  "end_date": "2026-08-02",
  "days": [
    {
      "day": 1,
      "date": "2026-08-01",
      "items": [
        {
          "name": "故宫",
          "category": "scenic",
          "arrival": "09:00",
          "ticket_required": true,
          "price": 60.0
        }
      ]
    }
  ]
}
```

### 3.4 B 如何提醒 A

B 通过 `decision_hook` 主动提醒 A。

触发时机：`ExecutionAgent` 判定事件显著时（降雨 ≥60%、排队 ≥阈值、交通延误 ≥30min）。

```python
req = DecisionRequest(
    events=[event],
    current_timeline=self.timeline,
    context={
        "impact_threshold": 50.0,
        "tool_specs": [...],
    },
)

replan = self.decision_hook(req)
```

A 返回：

- `ReplanRequest`：表示需要重规划
- `None`：表示不重规划

B 收到 `ReplanRequest` 后会自动：

- 更新时间轴
- 重建监控规则
- 记录到 `replan_history`
- 追加 `timeline_history`

A **不需要**关心 B 如何应用，只需保证返回符合 `ReplanRequest` 契约。

### 4.2 C 如何获取数据

C（Android）通过 HTTP REST + JSON 获取。

基础地址：

```text
http://<server>/api/
```

示例：

```http
GET /api/timeline/
GET /api/events/?since=0
GET /api/actions/
GET /api/replans/
```

事件流推荐**增量轮询**：

1. 第一次：`GET /api/events/?since=0`
2. 记录返回的 `total`
3. 下次：`GET /api/events/?since=<total>`

导出文件支持直接下载：

```http
GET /api/export/ics/?raw=1
GET /api/export/markdown/?raw=1
```

当前单用户 Demo 无需认证；后续多用户时需增加 Token。
